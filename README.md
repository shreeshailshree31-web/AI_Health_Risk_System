# 🏥 AI-Powered Preventive Healthcare Risk Assessment System

An AI-based preventive healthcare system that analyzes health and lifestyle parameters and provides personalized general health recommendations.

## 🚀 Live Demo

https://aihealthrisksystem-production-6f5d.up.railway.app/

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Random Forest
- MongoDB Atlas
- HTML
- CSS
- JavaScript
- Railway

## ✨ Features

- User Registration & Login
- AI-Based Health Risk Assessment
- BMI Calculation
- Personalized Recommendations
- Assessment History
- MongoDB Database
- Cloud Deployment

## ⚠️ Disclaimer

This project is an educational prototype for preventive health risk assessment and is not intended for medical diagnosis or treatment.
